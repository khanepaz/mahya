# دنیای جادویی محیا | Mahya's Magical World

وب‌اپلیکیشن فارسی، کاملاً واکنش‌گرا، کودکانه و تعاملی برای دختر ۷ ساله.

**شعار:** بازی کن، خیال کن، یاد بگیر و دنیا را رنگی‌تر کن!

## اجرا

```bash
python -m http.server 8080
```
سپس `http://localhost:8080`

## قابلیت‌های جدید هوش مصنوعی

### نقاشی → سبک جادویی
در استودیوی هنر، بعد از نقاشی یکی از سبک‌ها را بزنید (گیبلی، واقعی، کارتونی، آبرنگ، مصور).
- نیاز به مدل **vision** در Clean API
- تأیید والد قبل از ارسال تصویر
- خروجی: توصیف سبک + پرامپت انگلیسی (تولید تصویر واقعی فقط اگر مدل image-output داشته باشد)

### عکس صفحه کتاب → سؤال
در مدرسه رنگین‌کمانی، عکس صفحه کتاب را بارگذاری کنید تا هوش مصنوعی موضوع را بخواند و ۳ سؤال بسازد.

### بازی‌های AI
در سرزمین معماها:
- حدس کلمه با AI
- الگوی عددی جدید با AI
- معمای تازه با AI

## اتصال Clean API

- پایه: `https://www.cleanapis.com/v1`
- مدل متن: مثلاً `grok-4.5`
- برای تصویر: از «دریافت مدل‌ها» مدلی با **Vision** انتخاب کنید
- کلید فقط در حافظه نشست (تنظیمات والد، کد `1234`)
