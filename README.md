# دنیای جادویی محیا | Mahya's Magical World

وب‌اپلیکیشن فارسی، کاملاً واکنش‌گرا، کودکانه و تعاملی برای دختر ۷ ساله.

**شعار:** بازی کن، خیال کن، یاد بگیر و دنیا را رنگی‌تر کن!

## اجرا

فقط فایل `index.html` را در مرورگر باز کنید (Chrome توصیه می‌شود).

برای دسترسی کامل به دوربین و میکروفون و جلوگیری از محدودیت‌های `file://`، از سرور محلی استفاده کنید:

```bash
# با Python
python -m http.server 8080

# یا با npx
npx serve .
```

سپس به `http://localhost:8080` بروید.

## ۱۲ بخش اصلی

1. **کارخانه قصه‌های جادویی** — داستان‌سازی با کلمات، صدا و انتخاب تعاملی + ذخیره
2. **مدرسه رنگین‌کمانی** — بازی‌های ریاضی، حروف، شمارش و شکل (کاملاً محلی)
3. **استودیوی جادویی هنر** — بوم نقاشی واقعی با Canvas، ذخیره، دانلود PNG و گالری
4. **جنگل اسرارآمیز** — حیوانات، حدس از سرنخ، ساخت حیوان خیالی
5. **کارگاه مخترع‌های کوچک** — تمرین خلاقیت، دفتر ایده
6. **دوست کوچولوی یادگیری** — دستیار تکالیف (نیازمند Clean API)
7. **جعبه موسیقی قصه‌ها** — شعر و داستان + Text-to-Speech مرورگر
8. **تقویم رنگین‌کمانی من** — برنامه‌ریزی روزانه با ذخیره محلی
9. **آشپزخانه کوچولوی رنگی** — دستورهای ساده + تایمر (با حضور بزرگسال)
10. **کارگاه دست‌های جادویی** — کاردستی‌های کاغذی مرحله‌به‌مرحله
11. **سرزمین معماهای رنگی** — بازی‌های فکری کاملاً محلی (حافظه، الگو، شکل متفاوت، حدس کلمه)
12. **باغ رؤیاهای محیا** — دفتر آرزوها و سیاره شخصی

## اتصال Clean API

- آدرس پایه پیش‌فرض: `https://www.cleanapis.com/v1`
- مدل آزمایش‌شده: `grok-4.5`
- کلید API را فقط از **تنظیمات والد** (کد پیش‌فرض: `1234`) وارد کنید.
- کلید **فقط در حافظه نشست مرورگر** نگه داشته می‌شود و در `localStorage` یا فایل ذخیره نمی‌شود.
- پس از بستن صفحه باید دوباره وارد شود.

### هشدار امنیتی

استفاده مستقیم از کلید API در مرورگر کاملاً امن نیست؛ کد سمت مرورگر و درخواست‌های شبکه ممکن است قابل مشاهده باشند. برای استفاده مستمر، معماری بک‌اند یا واسط محلی توصیه می‌شود.

### کنترل مصرف

- هیچ درخواستی هنگام باز شدن صفحه یا تایپ ارسال نمی‌شود.
- همه درخواست‌ها با اقدام صریح کاربر انجام می‌شوند.
- بازی‌ها، نقاشی و برنامه روزانه توکن مصرف نمی‌کنند.
- تاریخچه مکالمه محدود است.
- خطاهای شبکه و HTTP به فارسی نمایش داده می‌شوند.

## امکانات محلی (بدون API)

- صفحه اصلی و ناوبری
- بوم نقاشی + ذخیره/بارگذاری/دانلود
- تمام بازی‌های فکری و آموزشی
- برنامه‌ریزی روزانه
- گالری آثار و گنجینه
- محتوای حیوانات و دستورهای آشپزی/کاردستی
- آواتار و سیستم ستاره
- Text-to-Speech و Speech Recognition (در صورت پشتیبانی مرورگر)

## قابلیت‌های وابسته به API که نیاز به بررسی دارند

- تولید داستان/شعر پیشرفته و دستیار تکالیف (با `POST /chat/completions` پیاده‌سازی شده)
- تحلیل تصویر / OCR / تولید تصویر (در این نسخه فعال نشده‌اند چون endpoint تصویری تأیید نشده)

## حریم خصوصی کودک

- بدون تبلیغات، خرید درون‌برنامه‌ای یا شبکه اجتماعی
- بدون جمع‌آوری اطلاعات شخصی حساس
- تصاویر و صدا فقط با اقدام کاربر
- کلید API هرگز در داده‌های کودک ذخیره نمی‌شود
- امکان پاک کردن تمام داده‌های محلی از پنل والد

## توسعه

پدر محیا می‌تواند پروژه را روی کامپیوتر شخصی اجرا کند. برای توسعه بیشتر می‌توان فایل‌ها را جدا کرد یا بک‌اند امن برای کلید API اضافه کرد.
