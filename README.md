# دنیای جادویی محیا | Mahya's Magical World

وب‌اپلیکیشن فارسی، کاملاً واکنش‌گرا، کودکانه و تعاملی برای دختر ۷ ساله.

**شعار:** بازی کن، خیال کن، یاد بگیر و دنیا را رنگی‌تر کن!

## اجرا

فقط فایل `index.html` را در مرورگر باز کنید (Chrome توصیه می‌شود).

برای دسترسی کامل به دوربین و میکروفون و جلوگیری از محدودیت‌های `file://`، از سرور محلی استفاده کنید:

```bash
# با Python
python -m http.server 8080

# یا با npx
npx serve .
```

سپس به `http://localhost:8080` بروید.

## ساختار فایل‌ها

| فایل | نقش |
|------|-----|
| `index.html` | رابط کاربری |
| `style.css` | ظاهر کودکانه |
| `app-part1.js` | وضعیت، خانه، قصه، مدرسه، ذخیره‌سازی، پشتیبان |
| `app-paint-fix.js` | بوم نقاشی لمسی + Undo چندمرحله‌ای |
| `app-part2.js` | حیوانات، اختراع، شعر، بازی‌ها، گنجینه |
| `app-ai.js` | اتصال Clean API، Vision، استایل‌نقاشی، تحلیل کتاب |

## ۱۲ بخش اصلی

1. **کارخانه قصه‌های جادویی** — داستان‌سازی با کلمات، صدا و انتخاب تعاملی + ذخیره
2. **مدرسه رنگین‌کمانی** — بازی‌های ریاضی، حروف، شمارش و شکل (کاملاً محلی)
3. **استودیوی جادویی هنر** — بوم نقاشی واقعی با Canvas، Undo چندمرحله‌ای، ذخیره، دانلود PNG و گالری
4. **جنگل اسرارآمیز** — حیوانات، حدس زدن، ساخت موجود خیالی
5. **کارگاه مخترع‌های کوچک** — ایده‌پردازی و اختراع
6. **دوست کوچولوی یادگیری** — پرسش درسی با AI
7. **جعبه موسیقی قصه‌ها** — شعر و داستان کوتاه
8. **تقویم رنگین‌کمانی من** — برنامه روزانه
9. **آشپزخانه کوچولوی رنگی** — دستورهای ساده با هشدار ایمنی
10. **کارگاه دست‌های جادویی** — کاردستی
11. **سرزمین معماهای رنگی** — حافظه، الگو، معما
12. **باغ رؤیاهای محیا** — آرزوها و سیاره شخصی

## اتصال Clean API

- آدرس پایه پیش‌فرض: `https://cleanapis.com/v1`
- مدل آزمایش‌شده: بسته به سرویس (از «دریافت مدل‌ها» استفاده کنید)
- کلید API را فقط از **تنظیمات والد** (کد پیش‌فرض: `1234`) وارد کنید.
- کلید فقط در حافظه نشست مرورگر نگه داشته می‌شود و در مخزن یا پشتیبان ذخیره نمی‌شود.

**توجه امنیتی:** کد ورود والد فقط برای جلوگیری از تغییر تصادفی توسط کودک است و امنیت واقعی محسوب نمی‌شود.

## قابلیت‌های AI (نیازمند کلید)

- تبدیل سبک نقاشی (گیبلی، کارتونی، آبرنگ و …) — نیاز به مدل Vision
- تحلیل عکس صفحه کتاب و ساخت سؤال
- ساخت قصه، شعر، معما و ادامه داستان
- قبل از ارسال هر تصویر، تأیید والد گرفته می‌شود

## پشتیبان‌گیری

در تنظیمات والد:

- **خروجی پشتیبان**: فایل JSON از تمام آثار (نقاشی، داستان، ایده و …)
- **بازیابی**: بارگذاری همان فایل

نقاشی‌ها محدود به ۱۲ مورد اخیر نگه داشته می‌شوند تا از پر شدن `localStorage` جلوگیری شود.

## تغییرات نسخه اخیر (اولویت صفر)

- حذف تکرار توابع `callAPI` / `testApi` (نسخه قوی‌تر در `app-ai.js` استفاده می‌شود)
- محدود کردن تعداد و حجم نقاشی‌های ذخیره‌شده + پیام واضح کمبود فضا
- تأیید دو مرحله‌ای قبل از پاک‌کردن همه داده‌ها
- تأیید قبل از حذف تک‌تک نقاشی‌ها
- رندر امن‌تر گالری (ساخت DOM به‌جای تزریق خام `innerHTML`)
- Undo چندمرحله‌ای بوم نقاشی (تا ۲۵ مرحله)
- قابلیت خروجی و بازیابی پشتیبان
- یادداشت صریح درباره محدودیت قفل والد
- صفحه اصلی با بنر خوش‌آمدگویی و ۴ کارت اصلی (الهام از طراحی پاستلی)

## محدودیت‌های فعلی

- داده‌ها فقط روی دستگاه (localStorage) هستند؛ انتقال بین دستگاه‌ها فقط از طریق فایل پشتیبان ممکن است.
- کلید API در مرورگر قابل مشاهده است (معماری سمت‌کلاینت).
- تولید تصویر واقعی فقط در صورتی کار می‌کند که مدل/سرویس واقعاً خروجی تصویری بدهد.
- بسیاری از بخش‌های آموزشی بدون اینترنت کامل کار می‌کنند؛ بخش‌های AI نیاز به اتصال دارند.
