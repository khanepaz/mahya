# دنیای جادویی محیا | Mahya's Magical World

وب‌اپلیکیشن فارسی، کاملاً واکنش‌گرا، کودکانه و تعاملی برای دختر ۷ ساله.

**شعار:** بازی کن، خیال کن، یاد بگیر و دنیا را رنگی‌تر کن!

## اجرا

فقط فایل `index.html` را در مرورگر باز کنید (Chrome توصیه می‌شود).

برای دسترسی کامل به دوربین و میکروفون، بهتر است از یک سرور محلی استفاده کنید:

```bash
# با Python
python -m http.server 8080

# یا با npx
npx serve .
```

سپس به `http://localhost:8080` بروید.

## ۱۲ بخش اصلی

1. **کارخانه قصه‌های جادویی** — داستان‌سازی با کلمات، صدا و انتخاب تعاملی
2. **مدرسه رنگین‌کمانی** — بازی‌های ریاضی، حروف، شمارش و شکل (محلی)
3. **استودیوی جادویی هنر** — بوم نقاشی واقعی با Canvas، ذخیره و گالری
4. **جنگل اسرارآمیز** — حیوانات، بازی حدس، ساخت حیوان خیالی
5. **کارگاه مخترع‌های کوچک** — تمرین‌های خلاقیت و دفتر ایده
6. **دوست کوچولوی یادگیری** — دستیار تکالیف (نیازمند API)
7. **جعبه موسیقی قصه‌ها** — شعر و داستان با Text-to-Speech
8. **تقویم رنگین‌کمانی من** — برنامه‌ریزی روزانه با ذخیره محلی
9. **آشپزخانه کوچولوی رنگی** — دستورهای ساده + تایمر (با حضور بزرگسال)
10. **کارگاه دست‌های جادویی** — کاردستی‌های کاغذی مرحله‌به‌مرحله
11. **سرزمین معماهای رنگی** — بازی‌های فکری کاملاً محلی (حافظه، الگو، ...)
12. **باغ رؤیاهای محیا** — دفتر آرزوها و سیاره شخصی

## اتصال Clean API

- آدرس پایه پیش‌فرض: `https://www.cleanapis.com/v1`
- مدل آزمایش‌شده: `grok-4.5`
- کلید API را فقط از **تنظیمات والد** (کد پیش‌فرض: `1234`) وارد کنید.
- کلید **فقط در حافظه نشست مرورگر** نگه داشته می‌شود و در localStorage یا فایل ذخیره نمی‌شود.
- پس از بستن صفحه باید دوباره وارد شود.

### هشدار امنیتی

استفاده مستقیم از کلید API در مرورگر کاملاً امن نیست؛ کد سمت مرورگر و درخواست‌های شبکه ممکن است قابل مشاهده باشند. برای استفاده مستمر، معماری بک‌اند یا واسط محلی توصیه می‌شود.

### کنترل مصرف

- هیچ درخواستی هنگام باز شدن صفحه یا تایپ ارسال نمی‌شود.
- همه درخواست‌ها با اقدام صریح کاربر انجام می‌شوند.
- بازی‌ها و نقاشی و برنامه روزانه توکن مصرف نمی‌کنند.
- تاریخچه مکالمه محدود است.

## امکانات محلی (بدون API)

- صفحه اصلی و ناوبری
- بوم نقاشی + ذخیره/بارگذاری
- تمام بازی‌های فکری
- برنامه‌ریزی روزانه
